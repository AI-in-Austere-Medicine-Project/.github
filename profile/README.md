# AI in Austere Medicine Project (AI-AMP)

Open-source clinical decision support for clinicians working without reliable power, internet or physician backup. Guideline-grounded, clinician-signed, and small enough to run offline on hardware you can carry.

> **Research prototype.** Not for patient care. Simulated scenarios only. Enter no patient information.

### Projects

**EdgeCDSS**: guideline search and dose support on an NVIDIA Jetson. An on-device model writes the answer; every dose is signed against its source page and checked by code before you see it.
[Open the portal](https://cdss.arcanekg.com) · [pi-cloud-cdss](https://github.com/AI-in-Austere-Medicine-Project/pi-cloud-cdss)

**EdgeCDSS Pocket**: a wearable voice dose assistant. It reads back what it heard, then speaks the dose. Fixed vocabulary, signed doses only, no language model.
[Try it in your browser](https://cdss.arcanekg.com/pocket) · [edgecdss-pocket](https://github.com/AI-in-Austere-Medicine-Project/edgecdss-pocket)
